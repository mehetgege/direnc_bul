# direnc_bul

Tek dosya mimarisine (`index.html`) odaklanan, canlı piyasa verisiyle çalışan bir **Trading Komuta Merkezi** prototipidir.

## Çalıştırma

Statik bir web sunucusu ile `index.html` dosyasını açmanız yeterlidir.

## Dosya Notları

- `index.html`: aktif ve geliştirilen ana uygulama dosyası.
- `indx.html`: eski/legacy sürüm dosyası; geriye dönük referans için tutulur, ana giriş noktası değildir.
